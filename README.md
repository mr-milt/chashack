# ChasHack

A site introducing our group: who we are and what each of us does.

Live at https://mr-milt.github.io/chashack/

Made at ChasHack by Milton, Abiha, Alex and Gillian.

## Running it

You need Node 20 or newer.

```bash
git clone https://github.com/mr-milt/chashack.git
cd chashack
npm install
npm run dev
```

That starts a dev server, usually on http://localhost:5173.

`npm run build` puts the finished files in `dist/`, `npm run preview` serves those so you can check them before pushing, and `npm run lint` runs Oxlint over the code.

## Built with

React and React Router for the pages, Tailwind for styling, Vite for the build. Hosted on GitHub Pages.
